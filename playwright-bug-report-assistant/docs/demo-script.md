# 90-second portfolio demo

1. Run a synthetic checkout test successfully.
2. Change its expected button and rerun it.
3. Open the failure screenshot and Markdown summary.
4. Show the category, explanation, and repository-validated line.
5. Explain deterministic fallback and optional OpenAI enhancement using `analysisMetadata`.
6. Show alternating outcomes and the stability observation.
7. Finish with the installable reporter, CLI, and privacy controls.

Label every scenario as demonstration data, not client work.
